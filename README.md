# Simple Unity Hotbar

A small 2D hotbar prototype built with Unity and C#.

## Features

- Five inventory slots
- Item names and quantities displayed in the UI
- Item data configured through the Unity Inspector
- Keyboard selection using keys 1–5
- Visual highlight for the selected slot

## Built With

- Unity
- C#

## What I Learned

- Creating and using C# classes
- Working with arrays and serializable data
- Connecting UI elements through the Unity Inspector
- Updating UI text and colors through scripts
- Handling keyboard input
- Using Git and GitHub for version control

## Purpose

This project was created as a small learning exercise while studying Unity and C#.
